# BSA 01: Анализ заинтересованных сторон

## Описание проекта
Проект посвящен выявлению заинтересованных сторон (стейкхолдеров) для ИТ-систем. В рамках работы требовалось определить всех участников процессов, которые могут влиять на систему или зависеть от нее. 

Для практики использовались 2 бизнес-задачи: создание онлайн-записи для сети барбершопов и сервис доставки заказов.

## Выполненные задачи

### 1. Каталогизация заинтересованных сторон
Создан каталог стейкхолдеров с их атрибутами. Выделены категории (организация системы, затрагиваемые стороны, регуляторы, проектная команда), а также определен уровень их контактности с системой (по луковичной диаграмме) и проектные роли.
**Артефакт:** `ex00_<префикс>_stakeholders.xlsx`

### 2. Построение луковичной диаграммы
Для визуализации окружения системы построена луковичная диаграмма. Определены слои взаимодействия (от команды разработки до внешних регуляторов). На диаграмму нанесены как роли из условия задачи, так и дополнительные участники, характерные для реальной бизнес-среды.
**Артефакт:** `ex01_<префикс>_onion.png` (или .docx)

### 3. Выявление интересов, потребностей и проблем
Для каждого стейкхолдера сформулированы его интересы, потребности к системе и текущие проблемы.
**Артефакт:** `ex02_<префикс>_needs.xlsx`

### 4. Дополнение глоссария
В глоссарий проекта внесены новые понятия, связанные с темой заинтересованных сторон и луковичной диаграммы.
**Артефакт:** `ex03_<префикс>_glossary.xlsx`


## Стек и инструменты
* **MS Excel** (составление каталогов, таблицы интересов и потребностей)
* **MS PowerPoint** (построение луковичной диаграммы)
